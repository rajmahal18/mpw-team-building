# Phase 4 Handoff

Phase 4 should build **organizer authoring UX over the existing engine**, not invent a second activity model.

Priority order:

1. schema-driven Activity Builder;
2. block add/edit/reorder UX;
3. rich question authoring (MCQ/multi-select/text/numeric first);
4. scoring builder that emits the existing score AST;
5. verification/timing/attempt settings;
6. reusable Activity Library templates;
7. duplicate/modify/save-as-template;
8. event preflight screen;
9. only basic coherent visual polish needed for usability.

Do not replace typed configuration with page-specific form models. The form must serialize to the Phase 3 schemas.
