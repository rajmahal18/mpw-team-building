# Activity Dictionary — Broad Team-Building Catalog

Purpose: seed the reusable Activity Library and test whether the generic engine can represent real-world activity families. These are templates, never hardcoded behavior.

Each template should eventually have tags such as `physical`, `mental`, `creative`, `communication`, `indoor`, `outdoor`, `wet`, `low-impact`, `marshal-required`, `auto-scoreable`, `team-vs-team`, etc.

## 16. Hybrid composite patterns

Many real events are combinations, e.g.:

- run to station -> scan QR -> answer quiz -> perform physical task -> marshal approves -> receive clue;
- solve puzzle -> reveal code -> enter code -> unlock next checkpoint;
- photo submission -> judge scores creativity -> score updates leaderboard;
- relay time + quiz accuracy -> weighted combined score;
- tournament win -> unlock bonus challenge;
- randomized station route -> final meta-puzzle uses collected tokens.

The engine must support these compositions without creating a new hardcoded “game type.”
