# First MPW Pilot Checklist

Run this against a small real rehearsal before a full event.

## Organizer dry run

- configure event identity, terminology, privacy and theme;
- create representative teams and participant records;
- install/customize activities without code changes;
- build stations and routes, rotate QR credentials, and print/display them;
- run preflight and resolve every blocking issue;
- move through the intended lifecycle states;
- test pause/resume, station capacity, queues, reroutes and announcements;
- enter scoring and verify canonical leaderboard output;
- review media moderation, audit logs and CSV exports.

## Device/venue rehearsal

Use at least one current Android device and one iPhone if available. Test normal camera QR scanning, weak signal, reconnect, offline outbox recovery, media upload limits, outdoor readability and projector readability.

## Reconciliation

Classify every pilot finding as one of: configuration/documentation problem, generic UX defect, generic engine defect, infrastructure issue, or training issue. Do not solve a pilot problem by adding an MPW-event-specific code branch.
